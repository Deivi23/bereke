# Береке — учёт магазина

Веб-приложение (PWA): работает в браузере телефона и ноутбука, ставится на главный экран, не требует интернета после первой загрузки.

**Онлайн-версия:** https://deivi23.github.io/bereke/

Обновление: `MSYS_NO_PATHCONV=1 BASE_PATH=/bereke/ npm run build`, затем содержимое `dist` отправить в ветку `gh-pages`.

## Что уже есть

- **Касса** — поиск и штрихкод в одном поле (камера, USB-сканер или ввод вручную), плитки быстрых и популярных товаров по категориям, чек-лента справа (на телефоне выезжает снизу). Скидка в % или в тенге, отложенные чеки, оплата наличными со сдачей, картой, смешанная или в долг. Горячие клавиши на ноутбуке: F2 — поиск, F4 — оплата, Esc — закрыть окно. Чек можно напечатать.
- **История продаж и возвраты** — список чеков по дням, возврат части товара наличными, на карту или списанием с долга, отмена продажи целиком.
- **Смена** — открытие с суммой наличных в кассе, итоги (выручка, нал, карта, в долг, возвраты, оплаты долгов), закрытие с пересчётом и разницей.
- **Долги** — карточка клиента с историей, приём оплаты, запись старых долгов из тетради, напоминание в WhatsApp и звонок одной кнопкой.

- **Цена** — камера или сканер читает штрихкод, на экране крупно цена, остаток и наценка.
- **Товары** — каталог, поиск, фильтры «Мало» и «Без цены», несколько штрихкодов на товар, свой штрихкод для товаров без кода.
- **Приход** — сканируете товары поставки, указываете количество и закупочную цену, остатки обновляются.
- **Ценники** — печать на A4 (24 на лист, 3×8) через обычный принтер. Приложение само предлагает ценники, у которых изменилась цена.
- **Обзор** — выручка, прибыль и средний чек с сравнением с прошлым периодом, графики по дням и часам, способы оплаты, лучшие товары (по выручке, прибыли, количеству), ABC-анализ, деньги в залежавшемся товаре, заканчивающиеся товары, долги, выгрузка отчётов в CSV для Excel.
- **Настройки** — язык (русский / қазақша), название магазина и текст на чеке, импорт и экспорт товаров в CSV, резервная копия, синхронизация.

USB / Bluetooth сканер работает без настройки: он «печатает» код в поле ввода.

## Синхронизация между устройствами

Все устройства магазина могут работать с одними данными. Сервер — Supabase (бесплатного тарифа хватает). Без интернета всё продолжает работать, данные отправятся, когда связь появится.

**Как подключить (один раз, ~10 минут):**

1. Зарегистрируйтесь на supabase.com и создайте проект (New project). Запомните пароль базы, он нам не понадобится, но потеряете его — не страшно.
2. В проекте откройте **SQL Editor**, вставьте всё содержимое файла [`supabase/schema.sql`](supabase/schema.sql) и нажмите **Run**.
3. Откройте **Authentication → Users → Add user → Create new user**. Введите почту и пароль для магазина, поставьте галочку **Auto Confirm User**. Этим логином будут входить все устройства.
4. Откройте **Authentication → Sign In / Providers** и отключите **Allow new users to sign up**, чтобы посторонние не могли зарегистрироваться.
5. Откройте **Project Settings → API** и скопируйте **Project URL** и ключ **anon public**.
6. В приложении: **Ещё → Синхронизация** → вставьте адрес и ключ → «Подключить» → войдите почтой и паролем из шага 3. То же самое на каждом телефоне и ноутбуке.

Совет: сначала войдите на том устройстве, где уже есть данные (оно отправит их на сервер), потом на остальных. Не вносите один и тот же товар вручную на разных устройствах до подключения: появятся дубликаты.

**Как это устроено.** Каждая продажа, приход и корректировка — отдельная неизменяемая запись, остаток считается из них. Поэтому две кассы, продавшие один товар одновременно, не затирают друг друга. Правки самих товаров (цена, название) — побеждает более поздняя. Проверка сходимости: `npm run test:sync`.

## Запуск на ноутбуке

```bash
npm install
npm run dev
```

Откройте http://localhost:5173.

## Камера на телефоне

Браузер даёт доступ к камере только по HTTPS. Для телефона нужно выложить собранное приложение на хостинг с HTTPS:

```bash
npm run build
```

Папку `dist` можно залить на Cloudflare Pages, Netlify или GitHub Pages.

## Ограничения

- Без подключённого сервера данные хранятся **на устройстве** (в браузере). Делайте резервную копию в разделе «Настройки».
- Один общий логин на весь магазин, ролей «продавец / владелец» пока нет.
- Нет аналитики и сроков годности (следующие этапы).
- Чек, который печатает приложение, не является фискальным. Фискализация и Kaspi пока не подключены.
- Казахские переводы нужно проверить носителем языка.
